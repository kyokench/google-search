# かんたんGoogle検索

## Edgeへのインストール

1. Edgeのアドレス欄に `edge://extensions` と入力します。
2. 「開発者モード」をオンにします。
3. 「展開して読み込み」を押し、この `edge_google_search` フォルダーを選びます。
4. Edgeの拡張機能メニューで「かんたんGoogle検索」をツールバーに表示すると便利です。

## 使い方

- 虫眼鏡アイコンを押し、キーワードを入力してEnterまたは「Googleで検索」を押します。
- ページ上の文字を選択し、右クリックの「…をGoogleで検索」でも検索できます。
- 結果は新しいタブに開きます。

最近の検索を最大20件、端末内に保存します。同じ言葉は最新の位置に移動します。入力中は一致する履歴を表示し、クリックすると再検索できます。各行の「×」で個別削除、「すべて削除」で全件削除できます。右クリック検索も履歴に保存します。この拡張以外で行った検索や、追加前の検索は表示されません。

履歴はクラウド同期しません。検索を実行すると、キーワードをGoogleの検索URLに渡します。Google公式の拡張ではありません。
